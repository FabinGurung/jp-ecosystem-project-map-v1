    <section class="architecture">
      <h3>Machine-first architecture</h3>
      <p>Google Drive is the canonical source/evidence warehouse. GitHub is the canonical structured-data/control warehouse. PostgreSQL-compatible SQL text defines the relationship contract; CSV/JSON hold current values; JSONL holds history. The current GitHub Pages runtime does <b>not</b> require a live Neon/PostgreSQL server. Sheets, Pages and Slack remain downstream projections or controlled input surfaces.</p>
