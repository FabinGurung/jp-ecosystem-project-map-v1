Machine-first architecture

Google Drive is the canonical source/evidence warehouse. GitHub is the canonical structured-data/control warehouse. PostgreSQL-compatible SQL text defines the relationship contract; CSV/JSON hold current values; JSONL holds history. The current GitHub Pages runtime does not require a live Neon/PostgreSQL server. Sheets, Pages and Slack remain downstream projections or controlled input surfaces.

Platform modules: Operations Hub is the current live-experience point. Standard modules are JP AEC Project Controls (Primavera P6), JP AEC Cost Estimation, JP AEC Structural Analysis (OpenSees), and JP AEC CAD & Drawings. Existing repository slugs remain unchanged for URL stability.
